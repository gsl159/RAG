> 基于前端代码 (`frontend/src/`) 详细阅读后绘制，覆盖全部 7 个页面及所有弹窗交互。

**侧边栏底部元素：**

### 2.3 AI 消息元信息栏（Meta Bar）

每条 AI 回复下方显示：

```
┌──────────────────────────────────────────────────────────────┐
│ [C2完整]  [降级C1·重试超时]  320ms  [缓存命中]                │
│ 置信度: ████████░░ 82%                    [🔗] [👍] [👎]    │
└──────────────────────────────────────────────────────────────┘
```

| 元素 | 说明 |
|------|------|
| 意图标签 | C0(绿/FAQ缓存)、C1(黄/轻量)、C2(蓝/完整) |
| 降级标签 | 仅当 `degrade_level ≠ C2` 时显示，含降级原因 |
| 延迟 | `latency_ms` |
| 缓存命中 | 绿色标签 |
| 置信度 | 进度条 + 百分比（≥75%绿/≥50%黄/<50%红） |
| 🔗 分享 | 生成分享链接到剪贴板 |
| 👍/👎 | 快速好评 / 打开差评弹窗 |

### 3.2 文档表格列说明

| 列 | 说明 |
|----|------|
| 文件名 | 最大 180px，超出省略 |
| 类型 | 灰色 Badge (PDF/DOCX/HTML/TXT/MD) |
| 标签 | 彩色标签芯片，可 [+] 添加，✕ 解绑 |
| 版本 | v1, v2... 覆盖上传递增 |
| 状态 | pending(灰), processing(蓝), done(绿), failed(红) |
| 质量分 | 进度条 + 百分比（≥80%绿，≥60%黄，<60%红） |
| 分块数 | chunk_count |
| 大小 | 自动格式化 B/KB/MB |
| 操作 | 完成→查看分块; 失败→重试; 全部→删除 |

### 3.6 实时通知

- **WebSocket** (`/api/ws/progress`) 推送文档处理状态变更
- 状态变 `done` → 浏览器通知 "文档处理完成"
- 状态变 `failed` → 浏览器通知 "文档处理失败: {error}"
- 断线 5s 自动重连

## 8. 全局交互特性总结

### 8.1 主题系统

| 主题 | 触发 | 存储 |
|------|------|------|
| 暗色（默认） | `data-theme` 属性无 | `rag_theme=dark` |
| 亮色 | `data-theme="light"` | `rag_theme=light` |
| 切换 | 侧边栏 🌗 按钮 | localStorage |

### 8.2 认证流程

```
用户输入凭证 → POST /api/auth/login
                  ↓
         返回 { token, user: { username, role } }
                  ↓
         localStorage 存储 rag_token + rag_user
                  ↓
         Axios 请求头自动附加 Authorization: Bearer {token}
                  ↓
         路由守卫检查 token 存在，否则跳转 /login
```

### 8.3 实时通信

| 通道 | 用途 | 页面 |
|------|------|------|
| SSE (`EventSource`) | 流式输出 AI 回复 | 智能问答 |
| WebSocket (`/api/ws/progress`) | 文档处理进度推送 | 文档管理 |
| HTTP 轮询 (30s) | 健康检查 | 全局侧边栏 + 问答页 |

### 8.4 响应式断点

| 断点 | 监控大盘 | 反馈页 |
|------|---------|--------|
| `> 1200px` | 6列统计卡 + 2列图表 | 4列统计卡 + 2列图表 |
| `≤ 1200px` | 3列统计卡 + 1列图表 | - |
| `≤ 640px` | - | 1列统计卡 + 1列图表 |

### 8.5 通用 UI 组件

| 组件 | 样式变体 |
|------|---------|
| Badge | `badge-green`, `badge-red`, `badge-yellow`, `badge-blue`, `badge-gray` |
| Button | `btn-primary`(蓝), `btn-accent`(蓝), `btn-ghost`(透明), `btn-danger`(红), `btn-sm` |
| Modal | 半透明遮罩 + 居中卡片，header/body/footer 三段式 |
| Table | `data-table` 深色行间隔，悬停高亮 |
| Loading | 三点跳动动画 `dots` |
